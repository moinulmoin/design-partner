# Design Partner privacy notice

Effective 2026-09-06. Published by Ideaplexa LLC; maintained by Moinul Moin.

Design Partner is a downloadable collection of instructions and reference files. The plugin does not operate a backend, require a Design Partner account, include an MCP connection, or include its own analytics or telemetry code. The bundled Python installer copies files locally and preserves a previous installation in a local backup directory.

When you use the skill, your chosen AI host processes your prompts, project files, screenshots, and tool results according to that host's settings and policies. The skill can guide the host to inspect or modify project files and use available browser tools within your request. Installing this plugin does not make your work private from the host or from services you choose to use through its tools.

Downloading through GitHub, a plugin directory, or the skills CLI is subject to those services' data practices. For example, the skills CLI documents installation telemetry. Design Partner does not control those services or their telemetry settings.

If you open a GitHub issue, the information you post is public and may be read by maintainers to answer the request. Do not include credentials, private source code, customer data, or personal information in public issues. Use GitHub's controls to manage or remove your own posts.

Questions about this package can be raised at https://github.com/moinulmoin/design-partner/issues without including sensitive data. For questions about how your AI host handles a conversation or project, contact that host directly.

Changes to this notice are recorded in this repository's version history.
